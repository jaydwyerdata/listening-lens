# Listening Lens

Turns Spotify listening history into a Streamlit dashboard, with a short AI-generated taste summary powered by Snowflake Cortex.

Open the Streamlit page from this app's tile to get started. No configuration needed for the bundled sample data path; see the full project README for the optional bring-your-own-data path.

Full documentation, architecture, and source: see the project repository this app was built from.
